# Un regalo per te

Piccolo sito statico per presentare un regalo speciale. E' pensato per essere pubblicato gratuitamente con GitHub Pages.

## Personalizzazione

1. Apri `index.html` e sostituisci `Il tuo nome` con il tuo nome.
2. Modifica il testo del messaggio direttamente nel biglietto.
3. Se vuoi, cambia il titolo della pagina e la descrizione nella sezione `<head>`.
4. Apri `index.html` nel browser per vedere il risultato.

## Pubblicazione su GitHub Pages

1. Crea un nuovo repository pubblico su GitHub.
2. Carica `index.html`, `styles.css`, `script.js` e `.nojekyll`.
3. Vai in **Settings > Pages**.
4. Seleziona la pubblicazione dal branch principale e dalla cartella `/root`.
5. GitHub mostrera' l'indirizzo del sito dopo pochi secondi.

Il progetto non richiede Node.js, installazioni o compilazione.
